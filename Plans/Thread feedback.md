**I’d keep the Phase 3 speedups, but I would not mark Gate P3 complete.** I reproduced two regressions that the existing threading tests miss.

| Priority | Finding | Recommended change |
|---|---|---|
| **High** | **Cancel and Move Now can be delayed while the main thread helps a descendant split.** During a nested wait, the `null-window poll` and `wide-window poll` check the borrowed split’s signal, not the original caller’s. In a controlled test, both waits polled more than 60 times in 250 ms without forwarding Cancel. The same test forwarded it when given the original signal. | Check the original signal during waits as well as during search. Add a test that cancels **after** the helping master enters a nested wait. |
| **High** | **A throwing progress callback can terminate the process.** The `null-window loop` and `wide-window loop` are `noexcept`, but can invoke the caller’s callback and only catch search aborts. With the same callback, my serial search returned the exception to the caller; the split search called `std::terminate`. | Stop the split, wait for its helpers without invoking the failing callback again, then propagate the exception on the calling thread. |
| **Medium** | **A heartbeat can report one move with another move’s score.** The master `reads the move and score separately`. A helper can publish an improvement between those reads. This affects live progress, not the final result. | Read the pair under the existing mutex, or publish it as one atomic value. |

**The benchmarks show faster searches, not consistently less work.** On `FFO 50–59 at 16 threads`, time improved from **74.40 s to 68.83 s**, but node inflation rose from **39.0% to 43.1%**. On `FFO 40–49`, inflation also rose slightly, from **22.0% to 22.4%**. Midgame depth 16 was faster than Phase 2, but going from 8 to 16 threads bought only **1.221 s → 1.216 s**. The `500 ms match` demonstrated a strength gain; the `2 s match` was positive but inconclusive. I’d record those distinctions against the `stated gate` rather than discard the faster engine.
